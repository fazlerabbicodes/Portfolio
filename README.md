# Personal Portfolio Website

A modern, responsive, and professional personal developer portfolio website for **Fazle Rabbi**, Computer Science & Engineering undergraduate at East West University. Built with semantic HTML5, modern CSS3 design tokens, and lightweight vanilla JavaScript (ES6+).

---

## 🎯 Current Focus & Interests

- **Learned Technologies:** CSS3 (Flexbox, CSS Grid, Responsive Design, Animations, Custom Properties) & HTML5
- **Current Technical Focus:** Modern JavaScript (ES6+), Web Applications, Artificial Intelligence (AI), and Node.js
- **Foundational Competencies:** Structured Programming in C, Object-Oriented Programming (OOP) in C++ and Java, Data Structures & Algorithms (DSA)

## 🚀 Key Features

- **🌓 Dynamic Dark / Light Mode:** Instant theme switcher with smooth CSS transitions, `localStorage` persistence, and automatic system theme detection (`prefers-color-scheme`).
- **⌨️ Typewriter Animation:** Dynamic cycling headline highlighting academic background, AI passion, and active development in JavaScript & Node.js.
- **💼 Original GitHub Projects Showcase:**
  - **⚡ Neon Cyberpunk Calculator:** Retro-futuristic calculator built with HTML5, CSS3, and JavaScript, featuring keyboard shortcuts, auto-scaling font, and math precision. [Live Demo on Render](https://fazlerabbicodes-simple-calculator.onrender.com/) &bull; [GitHub Repo](https://github.com/fazlerabbicodes/Simple-calculator).
  - **🎮 EWU CSE103 Quiz Game Application:** Modular C console application for East West University with persistent user authentication, admin control panel, 8 categories, and a 3-life scoring system. [GitHub Repo](https://github.com/fazlerabbicodes/ewu-cse103-quiz-project).
  - **🌐 Personal Developer Portfolio:** Open-source repository for this portfolio with dark/light themes, skills filter, and contact modules. [GitHub Repo](https://github.com/fazlerabbicodes/Portfolio).
  - **🤖 AI & Node.js Web App Lab:** Exploratory project space focusing on full-stack web applications and AI model integrations.
- **🎯 Interactive Skills Filter:** Filter skills dynamically across categories: *Current Focus (JS, Web Apps, AI, Node)*, *Learned Web (CSS, HTML)*, *Programming Languages*, and *CS Fundamentals & Tools*.
- **📋 One-Click Email Copy & Toast Feedback:** Seamless clipboard integration with interactive visual toast notifications.
- **✉️ Interactive Contact Module:** Quick contact form to easily start tech chats, AI discussions, and collaborative inquiries.
- **📱 Fully Responsive Design:** Mobile-first layout with smooth navigation drawer, sticky glassmorphism header, and fluid grid scaling across phones, tablets, and desktops.

## 💻 Local Preview

To preview the portfolio locally, you can open `index.html` in any web browser, or launch a simple local development server:

```bash
# Using Python 3
python3 -m http.server 8000

# Or using Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000` in your browser.
