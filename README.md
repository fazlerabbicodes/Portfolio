# Personal Portfolio Website

A clean, responsive, and lightweight personal portfolio website built with semantic HTML5 and vanilla CSS3. Designed to showcase academic background, technical skill sets, and contact details in a modern card-based layout.

---

## 🚀 Features

- **Semantic HTML5:** Built using standard, accessible elements (`<header>`, `<main>`, `<section>`, `<footer>`, `<table>`).
- **Responsive Layout:** Mobile-first approach using Flexbox, auto-scaling cleanly across phones, tablets, and desktops.
- **Card-Based UI:** Clean, modern visual hierarchy with subtle shadows, rounded borders, and custom pill badges.
- **Data Presentation:** Structured lists for academic history and a tabular breakdown for board exam GPAs.
- **Accessible Social Links:** External profile shortcuts with accessible `aria-label` tags and secure link targets (`rel="noopener noreferrer"`).

---

## 🛠️ Built With

- **HTML5** — Document structure and semantic hierarchy
- **CSS3** — Custom layout, Flexbox, transitions, and component styling
